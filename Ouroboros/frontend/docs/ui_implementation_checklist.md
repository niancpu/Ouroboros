# UI Implementation Checklist

## 文档使用方式

本清单用于第一版前端实现验收。页面设计以根设计文档为准，接口字段以 `docs\web_api` 为准。本清单只检查实现是否遵守已决约束。

## 全局视觉

- [ ] 全局默认 `border-radius: 0`。
- [ ] 不使用阴影、发光、模糊、玻璃拟态。
- [ ] 不使用渐变背景、渐变填充、面积渐变图表。
- [ ] 页面主体以白底、黑字、黑线框为主。
- [ ] 克莱因蓝只用于小面积强调，不铺满导航、页眉、整列侧栏或大块背景。
- [ ] 红绿只服务风险、异常、涨跌等金融语义。
- [ ] Hover 使用瞬间颜色反转或硬边线变化，不做漂浮、弹跳、呼吸动画。
- [ ] 不使用卡片嵌套卡片。
- [ ] 图表关闭默认主题、动画、阴影、圆角、渐变和灰色网格。

## CSS Token

- [ ] 颜色 token 至少覆盖纯白、纯黑、克莱因蓝、警戒红、增长绿。
- [ ] 字体 token 区分 serif 标题、sans UI/正文、mono 机器数据。
- [ ] 字号 token 固定，不随视口缩放。
- [ ] spacing token 以 `8px` 为基础，密集表格允许 `4px`。
- [ ] border token 区分 `1px` 内部线和 `2px` 主分区线。
- [ ] 控件高度 token 覆盖 `32px`、`40px`、`48px`。
- [ ] 状态 token 覆盖 `empty`、`loading`、`live`、`paused`、`recovering`、`error`、`terminal`。

## 布局与导航

- [ ] 顶部导航白底黑字，底部 `2px` 黑线。
- [ ] 当前页面使用 `3px` 克莱因蓝线标记。
- [ ] 页面按桌面专业工具实现，`1280px` 以下保留横向滚动，不改成移动卡片流。
- [ ] 主分区通过边框切割，不依赖大间距或柔和卡片。
- [ ] 工具栏高度固定为 `40px` 或 `48px`。
- [ ] 表格行高默认 `28px`，盘口窄条行高 `24px`。

## 初始化控制台

- [ ] 创建会话通过 Web API client，不直连内部模块。
- [ ] `agent_profile_set` 配平展示为可视化预览和本地草稿。
- [ ] 本地配平改动后显示本地草案状态。
- [ ] 当配平不影响真实请求时显示 `LOCAL PROFILE PREVIEW ONLY`。
- [ ] 创建失败不清空表单。
- [ ] 创建中锁定表单和启动按钮。
- [ ] 不写入 `Order_Input`、`Forum_Rumors`、`thought`。

## 实时推演画板

- [ ] 固定三栏：事件流、共识感染画布、盘口。
- [ ] 进入页面先加载 REST 快照，再应用 WebSocket 增量。
- [ ] `system.error` 进入事件流。
- [ ] 事件流不展示未来事实。
- [ ] 事件流不展示原始 `thought`、COT、Prompt、私有记忆。
- [ ] 盘口只展示 Web API 允许的聚合行情视图。
- [ ] 控制命令失败显示在操作按钮上方硬边错误条。

## 微型仪表盘节点

- [ ] 节点只能是绝对正圆或绝对正方形。
- [ ] 节点外侧使用 `1px` 或 `2px` 硬描边。
- [ ] 节点内部不写 Agent 名称。
- [ ] 节点上半部分表达信念值：蓝为看多，黑为看空，白或空心为观望。
- [ ] 节点底边用 `1px` 微型进度条表达 position exposure。
- [ ] 标签使用外部引线和等宽字体。
- [ ] 节点标签格式接近 `[AGT-14] C:0.85 P:70%`。
- [ ] 节点半径第一版固定在 `12px` 到 `18px`。
- [ ] 不用大圆表达重要性。
- [ ] 不使用阴影、渐变、发光、呼吸动画。

## Spotlight 与 Targeting Box

- [ ] Hover 节点进入 Spotlight Isolation。
- [ ] Spotlight 下只保留目标节点、直接来源、影响目标和相关连线为正常可见。
- [ ] 其他节点和边瞬间降至约 10% 透明度。
- [ ] 点击节点同步 Inspector 当前 Agent。
- [ ] 选中节点显示静态方形虚线 Targeting Box。
- [ ] Targeting Box 不旋转、不呼吸、不弹跳。
- [ ] Hover tooltip 只展示脱敏审计摘要和允许字段。

## 图谱边与剪枝

- [ ] 连线为 `1px` 纯黑或克莱因蓝。
- [ ] 箭头是锐利几何三角形。
- [ ] 不使用圆角箭头、粗线、光束。
- [ ] 默认隐藏低权重边。
- [ ] 默认只显示当前 Tick 有效影响。
- [ ] 上一 Tick 影响降为 10% 透明度或点状极细虚线。
- [ ] 24 个 Agent 默认不超过 48 条边。
- [ ] 超出阈值时按影响强度、当前 Tick、选中链路优先级裁剪。
- [ ] 图谱布局由前端确定性计算。
- [ ] 图谱布局结果不回传后端。

## REPLAY TICK

- [ ] Tick 刮擦器使用硬朗刻度和等宽标签。
- [ ] 拖动历史 Tick 时顶部显示 `REPLAY TICK`。
- [ ] 回放同步节点信念值、仓位进度条、连线显隐和曲线区间。
- [ ] 回放只读取前端缓存、REST 快照或 Web API 事件回放。
- [ ] 回放不触发启动、暂停、单步、停止等控制命令。
- [ ] 回到最新 Tick 后恢复 live、paused 或 terminal 状态。

## RECOVERING SNAPSHOT

- [ ] WebSocket 断线进入 `RECOVERING SNAPSHOT`。
- [ ] 恢复状态保留最终布局骨架。
- [ ] 收到需要快照的恢复信号后重新获取 REST 快照。
- [ ] 恢复过程不读取内部 Redis。
- [ ] 恢复完成后按 `seq` 去重合并后续事件。
- [ ] 恢复错误显示硬边错误条，不破坏全局导航。

## Inspector

- [ ] 智能体解剖室第一版是普通审计视图。
- [ ] 默认选中风险最高 Agent；无风险状态时选中列表第一项。
- [ ] 资产表只展示 Web API 允许的账户审计字段。
- [ ] 信念轨迹缺历史时显示当前点和空状态。
- [ ] 无公开因果链时显示 `NO PUBLIC CAUSAL CHAIN`。
- [ ] 审计流按调查笔录形式展示 Tick、事件引用、公开原因、风险标签。
- [ ] 审计流不做聊天气泡。

## 只读时间轴

- [ ] 页面标题区显示 `READ ONLY TIMELINE`。
- [ ] 只读展示历史事实轨和公开传闻轨。
- [ ] 当前 Tick 之后的插桩不显示正文。
- [ ] 当前 Tick 之后只显示类型、释放 Tick 和可见性。
- [ ] 不提供拖拽、删除、保存、发布按钮。
- [ ] 本地草案预览必须显示 `LOCAL DRAFT`。
- [ ] 本地草案不写 REST、WebSocket、Chronos SSOT 或内部 channel。

## 白皮书

- [ ] 报告页默认静态阅读，不自动刷新。
- [ ] 打印模式隐藏全局导航和运行控制。
- [ ] 崩塌概率只展示 Web API 或快照已有字段。
- [ ] 缺少崩塌概率字段时显示 `N/A`。
- [ ] 不由前端临时计算崩塌概率并伪装为系统结论。
- [ ] 虚拟龙虎榜只来自 Web API 允许的盘后数据。
- [ ] 风险排行只来自允许的 Agent 审计字段。
- [ ] 不提供报告结论回写推演入口。

## COT 与私有数据禁止项

- [ ] 普通前端不得展示原始 `thought`。
- [ ] 普通前端不得展示 COT。
- [ ] 普通前端不得展示 Prompt。
- [ ] 普通前端不得展示私有记忆。
- [ ] 普通前端不得展示 Agent 原始 payload。
- [ ] 普通前端不得展示内部 `UI_Audit`、`Order_Input`、`trade_batch`、`risk_result` 原始 payload。
- [ ] Tooltip、Inspector、事件流、白皮书、错误条都必须执行同一可见性过滤。
- [ ] 如未来需要原始 COT，必须另建沙盒外诊断能力、独立权限、独立审计日志和独立接口。

## 后置能力不得伪装

- [ ] 配平控件真实影响创建请求前，必须先有 Web API schema。
- [ ] 时间轴保存草案或发布插桩前，必须先有独立 Web API、权限和审计语义。
- [ ] 内部诊断视图上线前，普通审计视图仍禁止原始 COT。
- [ ] 后端未提供正式结论字段前，白皮书只能展示 `N/A` 或标记为前端展示摘要。
- [ ] 移动端体验未重新设计前，不实现移动端卡片流。
