# Referee Node 权限边界设计

## 目标

保留 A 股模拟中的信息不对称。裁判节点只负责播报可观察市场事实、生成 UI 审计视图，不得把 Agent 私有思考、机构意图、未公开订单理由转换为公共市场信号。

## 核心边界

切断 `thought` 到公共总线的逆向流通。

| 字段 | 归属 | 是否可影响市场 | 合法去向 |
| :--- | :--- | :--- | :--- |
| `thought` | Agent 私有审计材料 | 否 | `UI_Audit`，仅供 UI 渲染审查官生成前端可视化 |
| `action` | 交易动作 | 是 | `Order_Input`，进入 Layer 3 撮合引擎 |

任何公共广播不得引用、总结或暗示 Agent 的私有 `thought`。市场影响必须通过订单、成交、价格、盘口异动和延迟披露产生。

## 物理隔离后的两个实体

### 交易所数据播报员

输入：

- Layer 3 撮合引擎输出的匿名订单流。
- 最新成交价、成交量、买卖盘深度、涨跌停状态。
- 收盘后统计出的账户席位净买入/净卖出排名。

输出：

- `Tape_Alerts`：全员可见的盘中异动播报。
- `End_of_Day`：全员可见的盘后龙虎榜、收盘统计。

说明：标准 `Market_Price` / Level-2 快照由 Layer 3 直接发布。交易所数据播报员可以读取该快照和匿名订单流，但只负责生成解释性 `Tape_Alerts` 与盘后 `End_of_Day`。

禁止：

- 读取 Agent 私有 prompt、私有记忆、`thought`。
- 推断并广播身份绑定意图。
- 把 UI 审计结果转成 Agent 可订阅消息。

### UI 渲染审查官

输入：

- Agent 私有 `thought`。
- Agent `belief_shift`。
- 已公开论坛消息、订单动作、成交结果。

输出：

- 前端拓扑边。
- 脱敏后的可视化解释。
- 前端因果链时间线。
- 断线恢复用的因果链摘要。

隔离要求：

- 输出通道只能交给 `FrontendRealtimeGateway` 或 Web API 层生成前端协议事件。
- 输出不得写入 Agent 可订阅频道。
- 输出不得被 Layer 1、Layer 2、Layer 3 作为下一轮决策输入。
- REST 快照中的 `causal_chains` 只能保存脱敏摘要和最近事件引用，不得保存原始 `thought`。
- 普通 Web API 事件类型只能是 `audit.graph`、`audit.causal_chain` 或快照中的脱敏摘要，不得透传内部 `UI_Audit`、`Frontend_Audit_Graph` 或 `Frontend_Causal_Chain` 原始 payload。

## 合法播报示例

合法：

```text
【14:02 盘口异动】该股遭遇连续千手大单砸盘，当前跌幅扩大至 5%，下方买盘承接乏力。
```

非法：

```text
【14:02 机构动向】公募 B 认为估值过高，正在秘密出货。
```

合法：

```text
【盘后龙虎榜】今日买一席位为“拉萨团结路”，买入 5000 万；卖一席位为“机构专用”，卖出 8000 万。
```

## 未决取舍

- 龙虎榜粒度：真实席位风格名还是模拟席位分类名。
- UI 默认不展示原始 `thought`，普通前端/API 只展示脱敏摘要；沙盒外诊断通道如需开放，必须另行设计。
- 盘中异动阈值：第一版先用固定阈值，后续再改自适应。
