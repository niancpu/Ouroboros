# 2024-10-08 至 2024-10-11 机构/主力资金行为证据台账

本文只做资料搜集，用于支撑机构/主力类 agent profile 的事实底座；不做架构决策，不替主流程确定最终参数。时间窗口限定为 2024-10-08 至 2024-10-11，必要时引用 2024-09-24 以来或 2024-10-18 后续数据作为背景/校验。

## 来源等级与口径说明

| 等级 | 含义 | 使用方式 |
| --- | --- | --- |
| A | 官方、交易所、央行/证监会、交易所规则或公告 | 优先用于政策工具、披露机制、交易/两融定义、工具约束。 |
| B | 主流财经媒体转引交易所、Choice、Wind、银河证券基金研究中心、中证金融等数据 | 可用于日度成交、ETF 申赎/资金流、两融余额、主力资金统计；必须保留数据口径。 |
| C | 券商研报、公募/私募/卖方策略观点、采访表述 | 只作为机构预期、风险偏好、仓位约束的证据；不能当作真实成交。 |
| D | 口径不透明的资金流榜单、二次转载、市场传闻 | 只能作为辅助线索；若与 B 级数据冲突，应标注不可直接合并。 |

关键区分：

- ETF 申赎/净流入是基金份额、净值、交易和申赎口径的统计，不等同于某家主动基金主动买入。
- 融资余额、融资买入额是杠杆资金行为，不等同于机构资金，也不能全部归为散户。
- “主力资金”通常按成交单规模或数据商算法划分，是统计标签，不是可识别的单一机构主体。
- 机构观点/研报只说明当时预期和解释框架，不能当作已发生交易事实。
- SFISF 是流动性互换便利，不是央行直接买股；后续操作规则会影响机构风险偏好，但 10-10 当天主要是预期冲击。

| `information_delay` 存在 | 北向资金实时净买入口径自 2024-08-19 起调整；沪股通收市后公布成交总额、ETF 成交总额、前十大活跃证券等，不再适合沿用旧实时净买入信号。 | A | agent 的外资/北向信息通道应改为收盘后、成交额/活跃股口径，不能使用旧式盘中净流入。 |
| `new_fund_build_risk` 高 | 新基金需合同生效后建仓，指数基金需紧密跟踪，快速大开大合行情增加建仓难度；部分产品低仓错过上涨或上市前后被迫追高。 | B/C | 新基金 agent 不应默认满仓或完美择时；建仓期有踏空和接盘两端风险。 |

## 可转入 prompt/profile 的事实短句

- 2024-10-08 是成交与杠杆同时爆发日：两市成交约 3.45 万亿元，融资余额单日增加约 1070 亿元，融资交易额占 A 股成交额约 20%。
- 2024-10-08 至 2024-10-09 的增量资金核心通道之一是股票 ETF，宽基、创业板、科创/芯片 ETF 净流入居前。
- “主力资金”在 10-08 指数大涨日仍可显示大额净流出，说明它是大单/算法统计标签，不等同于机构统一买入。
- 券商和金融科技在 10-08 极度拥挤，10-10 至 10-11 出现明显大单净流出和高成交换手。
- 融资资金从 10-08 的千亿级净增，降至 10-10 的小幅净增，并在 10-11 转为净减少，说明杠杆资金追涨后快速受回撤约束。
- 2024-10-10 SFISF 提升证券、基金、保险公司流动性预期，但它是互换便利，不是央行直接买股。
- SFISF 合理映射方向是股票 ETF、沪深300成分股、宽基和高流动性资产，不应映射为无限制买入小盘题材。
- 公募基金整体仓位在 9 月底明显提升，但新基金在 10-08 至 10-11 面临踏空、追高建仓和净值波动压力。
- 机构观点普遍把 10-08 后调整解释为短期过热、获利回吐和财政预期修正；这些是解释框架，不是成交事实。

## 不可确认项与避免误用

- 不能确认“国家队”在 2024-10-08 至 2024-10-11 逐日买入了哪些股票；公开证据只能支持政策工具、ETF/宽基偏好和稳定流动性目标。
- 不能把股票 ETF 净流入全部归为机构主动加仓；其中可能包含散户申购、套利、做市、融资买入、机构配置等多来源。
- 不能把融资余额增加全部归为散户；两融账户包含个人与机构，且存在 50 万资产、交易经验、风险承受能力等门槛。
- 不能把“主力资金净流出”与“机构净卖出”划等号；数据商主力资金口径与龙虎榜机构席位口径不同。
- 不能使用 2024-08-19 前旧北向资金实时净买入口径复刻 2024-10-08 至 10-11 的盘中外资行为。
- 不能把 10-18 之后 SFISF 正式启动和首批申请额度，回填为 10-10 至 10-11 已实际入市成交；10-10 至 10-11 只能作为预期和风险偏好影响。
- 尚未找到 2024-10-08 至 10-11 逐日、全市场、可公开核验的“保险资金实际买入股票/ETF”成交明细；保险只能通过 SFISF 资格、长期资金政策和媒体/机构分析间接刻画。
