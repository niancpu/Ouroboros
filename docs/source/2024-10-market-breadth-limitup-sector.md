## market_state 草案

字段建议：

| 字段 | 类型 | 取值建议 | 说明 |
| --- | --- | --- | --- |
| `breadth_up_count` | integer/null | 当日上涨家数 | 优先使用同一供应商口径；若混用，记录 `breadth_source_scope`。 |
| `breadth_down_count` | integer/null | 当日下跌家数 | 与上涨家数同口径。 |
| `breadth_flat_count` | integer/null | 当日平盘家数 | 可为空。 |
| `breadth_ratio` | number/null | `up_count / (up_count + down_count)` | 10/8 约 0.945；10/9 约 0.055；10/10 约 0.574；10/11 约 0.086。上述示例分别基于表中优先口径。 |
| `limit_up_count` | integer/null | 收盘涨停数 | 明确是否含 ST、北交所、未开板新股。 |
| `limit_down_count` | integer/null | 收盘跌停数 | 10/9 建议保留 `854` 为主要新闻口径，同时记录备选 `789`、`900+`。 |
| `intraday_limit_up_touch_count` | integer/null | 盘中触及涨停但不一定封住的数量 | 10/8 可记录 2637 或拆成 `limit_up_count=791`、`failed_seal_count=1846`。 |
| `failed_seal_count` | integer/null | 炸板/封板未遂数量 | 10/8=1846、10/9=50 或 57、10/10=55、10/11=15/21，视口径而定。 |
| `seal_rate` | number/null | `limit_up_count / (limit_up_count + failed_seal_count)` | 用 0-1 小数；保留来源原值时可另存 `seal_rate_reported_pct`。 |
| `limit_event_tags` | string[] | 如 `intraday_thousand_limit_up_touch`、`limit_down_wave`、`broad_risk_off` | 10/8 不建议写成 `close_thousand_limit_up`；10/9 建议写 `limit_down_wave`。 |
| `sector_heat` | object | `{ "securities": 0.9, "fintech": 0.85, "semiconductor": 0.8 }` | 0-1 经验热度；由涨停扩散、行业涨跌幅、报道频率综合。 |
| `sector_rotation_note` | string | 简短中文标签 | 例如“金融科技/券商普涨后剧烈分化，半导体从扩散转为局部抗跌再转补跌”。 |
| `growth_board_pressure` | number/null | 0-1 | 用创业板指涨跌幅、创业板/科创高弹性题材跌幅、20cm 涨跌停数量综合。 |

## 口径限制

- “千股涨停”：10/8 可核验的是“沪深京三市超千股涨逾 19%”和“1846 只个股盘中一度触及涨停”，收盘涨停数公开复盘口径为 791。因此建模时不要标成“收盘千股涨停”，应标为 `intraday_thousand_limit_up_touch` 或 `intraday_extreme_up_limit_wave`。来源：[每经网](https://www.nbd.com.cn/articles/2024-10-08/3580175.html)、[新浪财经转载东方财富](https://finance.sina.com.cn/roll/2024-10-08/doc-incrvssx0387764.shtml)。
- 10/9 跌停潮：`854` 是界面新闻/多家综合报道使用的全日跌停口径；搜狐财经报道为“900 余股跌停”；金投网跌停个股表为 789。差异可能来自是否含 ST、北交所、临近跌停或统计时点不同。主字段可用 `854`，同时保留 `limit_down_count_alternates`。来源：[界面新闻](https://www.jiemian.com/article/11803991.html)、[搜狐财经/新浪](https://finance.sina.com.cn/roll/2024-10-09/doc-incrxvrt3113000.shtml)、[金投网](https://m.cngold.org/stock/xw9528641.html)。
- 涨停数与封板率在东方财富、财联社、21 财经之间有差异，常见原因是是否剔除 ST、退市股、未开板新股，以及是否统计北交所。入库时必须同时写入 `source_name`、`source_scope`、`exclude_st`、`exclude_new_stock`。
- 宽度数据也存在“沪深两市可交易 A 股”和“两市及北交所”差异。10/11 的 434/4616 与 439/4859 不应混为同一分母；建议选择 Wind/两市及北交所作为主宽度口径，21 财经沪深可交易 A 股作为对照。
- 行业/题材热度不是严格数值事实。本文给出的 `sector_heat` 是可解释的入模草案，正式实现应由涨停扩散、行业涨跌幅、成交额占比、报道主题词共同计算。
